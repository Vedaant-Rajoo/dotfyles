description: Start sessions with Ponytail Ultra and Caveman Ultra.
---

At the start of each session, read these installed skills and apply their modes:

- `~/.gemini/config/plugins/ponytail/skills/ponytail/SKILL.md`: Ponytail Ultra.
- `~/.gemini/config/skills/ultracave/SKILL.md`: Caveman Ultra (`ultracave`).

Keep each mode active until the user changes or stops it.
